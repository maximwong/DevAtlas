# DevAtlas 0.4.0

## 0.4.0：面向 LLM 的上下文导出（2026-10-29）

- 侧栏“导出 LLM 文件”支持选择项目/整个工作区，生成 UTF-8 Markdown 或结构化 JSON。
- 导出包含项目、导图、节点、连线、任务原文、状态、执行者、描述章节、稳定 ID、显式依赖与数据检查；项目范围会补齐传递依赖及必要关联。
- 缺失依赖、依赖循环在导出中明确标注；Done 仅表示记录状态，不替代独立验收。
- 新增只读工具 workspace_export_llm，当前共 26 个工具。CLI 支持 `export --project-id ID --output-dir DIRECTORY`，一次生成同一快照的 Markdown 与 JSON。
- 导出不读取接口凭据文件，不自动上传，文件为上下文快照，不是可回导的工作区备份；修改前仍需读取实时版本。
- 本轮累计 48 项测试、类型检查与构建通过；覆盖项目隔离、传递依赖、缺失/循环检查、Unicode 文件、CLI 真实 HTTP 导出及工作区不变。

## 0.3.1：Scrum 按任务类型配色（2026-10-29）

看板卡片的边框、浅色底纹和类型标签按类型自动显示：开发蓝色、测试橙色、学习绿色、Bug 红色、研究紫色；其他自定义类型为灰色。顶部提供类型图例。修改任务类型即更新配色，无需改写已有任务数据。原有标签色保留为个人标记圆点，编辑界面已注明其用途。

## 0.3.0：本机 LLM 操作接口（2026-10-29）

- 随桌面程序启动本地 HTTP API，只绑定 127.0.0.1 的动态端口；凭据保存在用户数据目录 automation.json，不应上传或写进提示词。
- GET /v1/tools 提供 25 个工具的参数 JSON Schema；GET /v1/workspace 提供工作区和版本；POST /v1/call 执行工具操作。
- 覆盖导图、节点、连线、任务、项目和 Sprint 的查询及编辑；支持节点批量复制、移动、删除和任务看板状态移动。
- scripts/devatlas-cli.cjs 是无需第三方依赖的调用入口：tools、workspace、health、call TOOL --args-file FILE；写操作自动读取版本，可用 --dry-run 预演。
- 界面和接口共用校验与写入队列；接口先等待界面保存，再检查 expectedRevision；冲突返回 409，编辑不会静默覆盖。接口提交会通知界面同步。界面发生冲突时可先导出 JSON，再重新读取。
- 每次实际写入保留最近备份；写操作必须带 requestId，同一应用进程内 5 分钟内的相同请求可幂等重试。重用编号但改变请求会被拒绝，重启后不保留幂等记录。
- 支持 dryRun；预演不落盘，但预演生成的 ID 不会被预留，后续操作应使用正式提交返回的 ID。
- 已通过 43 项测试、类型检查和构建。实际已安装 Electron 程序在独立配置中通过接口读写、IPC 保存握手、幂等、冲突、复制移动删除、磁盘及重启回读验证。桌面鼠标与视觉检查不在这些接口验证的覆盖范围内。

## 0.2.1：Scrum 分区扩展与拖放修复（2026-10-29）

- 分区随任务数量向下扩展，卡片保持正常高度，不设置四张卡片限制。各列保持同一行等高，窄窗口通过横向滚动查看其他分区。
- 鼠标进入分区标题、卡片、卡片之间空隙或底部空白均可移入；目标分区整列高亮。卡片落点保留插入排序，空白落点追加到该分区末尾。
- 拖放判定排除正在拖动的卡片，鼠标离开看板不会按旧卡片的重叠面积误判移动成功。
- 数据结构仍为版本 2。本轮累计 32 项测试、类型检查和构建通过。新增几何判定覆盖已有 12 张卡片时的多个落点；真实窗口尺寸与鼠标拖放尚未验收，桌面工具连接不可用。

## 0.2.0：多导图与批量编辑（2026-10-29）

- 可新建、命名和切换多张思维导图，各图单独显示节点和连线。
- 空白处左键拖动框选；Ctrl/Shift 加选；中键或右键平移。Ctrl+A 全选当前图。
- Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+X 剪切、Delete 删除，也有工具栏按钮。输入框使用原生文字快捷键。
- 使用应用内剪贴板，可跨导图粘贴。复制为独立节点，包含内部连线，不复制任务和项目绑定。
- 剪切先标记，粘贴时再移动，保持节点 ID 和任务/项目绑定；跨图移动断开原图中的边界连线，Esc 取消待执行剪切。退出应用会清空剪贴板，不会删除尚未粘贴的剪切节点。
- 工作区升级为 schemaVersion 2；读取 schemaVersion 1 时，全部旧节点迁入“原有思维导图”，保留节点、任务、项目 ID 及关联。旧格式 JSON 导入也支持迁移。旧版程序不能读取新版工作区；回滚必须同时恢复更新前的程序包和工作区备份。
- 本轮类型检查、构建和 23 项测试通过，涵盖迁移、多图、批量复制剪切和删除。画布 UI 测试使用适配层替身；真实桌面框选和拖拽尚未验收，桌面检查工具连接不可用。下方旧版交付验证记录保留为历史记录。

中文、离线优先的个人技术成长桌面工作空间。将技术画布、学习路线、项目与 Scrum 任务通过稳定 ID 关联，无账号和云数据库。

## 功能
- 无限画布：节点创建、双击改名、描述、类型、颜色、拖动、连线、关系标签、缩放、平移、适应视图、简单树布局。选中连线后 Delete 删除；删除节点需确认。
- 五列彩色任务看板：任务编辑、跨列拖动、列内排序、项目/类型/优先级筛选、Sprint 日期和完成统计。
- 节点关联多个任务，任务可搜索绑定多个节点；状态变化即时更新节点进度；任务可定位节点。
- 项目列表、可编辑详情、任务与技术视图，Dashboard 与系统/深色/浅色主题。
- 自动保存、JSON 导入导出、结构验证和最近备份。首次初始化演示工作空间，之后不覆盖用户修改。

## 技术栈与结构
Electron、React、TypeScript、Vite、React Flow、Zustand、dnd-kit、Zod、Vitest、electron-builder。
`src/model.ts` 数据模型；`src/store.ts` 自动保存；`src/main.tsx` 界面；`electron/` 受控 IPC 和文件存储；`tests/` 测试；`.github/workflows/ci.yml` Windows 构建；`docs/architecture.md` 关联设计。

## 开发
需要 Node.js 22+。
```sh
npm ci
npm run dev
```
浏览器预览：`npm run dev:web`，该模式数据仅保存在浏览器 localStorage。
```sh
npm run typecheck
npm test
npm run build
npm run dist:win
```
最后一条推荐在 Windows x64 执行；输出在 release/。CI 使用 windows-latest 生成 NSIS 安装包和便携 EXE，上传名为 DevAtlas-Windows-x64 的 Artifact。推送版本标签会创建 Release。尚未运行的工作流不代表安装包构建成功。

## Windows 安装运行
成功构建后，从仓库 Actions 下载并解压 Artifact，运行 DevAtlas Setup 0.1.0.exe，选择安装目录；也可以运行便携 EXE。不需要网络启动。未签名软件可能触发 SmartScreen，请确认来源后选择“更多信息 → 仍要运行”。本次尚未进行真人 Windows GUI 验证。

## 数据与备份
桌面版位于 Electron userData（通常 `%APPDATA%/DevAtlas/workspace.json`，具体目录依打包名称而定）。每次写入通过临时文件替换，旧版本保留为 workspace.json.bak。侧栏“恢复备份”读取备份，确认后替换当前状态。重要修改后请“导出 JSON”到独立目录。导入会替换整个工作区，先导出；无效结构会拒绝。读取失败时不自动覆盖原文件。

## 已知限制
- 无代码签名、无云同步、无多人协作；无燃尽图、复杂自动布局。
- Sprint 可以创建和分配，暂未提供编辑/删除界面；项目暂未提供删除。
- 自由布局通过直接拖动实现，树布局会覆盖当前坐标；环图仅提供简单排列。
- 未保存的防抖窗口内强制结束进程可能损失最后 250ms 的编辑；建议退出前确认“已自动保存”。
- 发布前需进行 Windows GUI、安装/卸载和高 DPI 手工验收。

## Windows 自动安装助手
解压源码 ZIP 后双击 `install-windows.cmd`。脚本检查 Node.js（缺失时尝试通过 winget 安装 LTS）、安装锁定依赖、构建 x64 安装包并启动安装向导。此过程需要网络和数分钟时间；失败时窗口保留错误，不能视为已安装。辅助脚本尚未在 Windows 实机验证。仅对本次脚本进程设置 PowerShell 执行策略，不更改系统策略。
